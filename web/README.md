# web — 가온생명 AX 어시스턴트 화면

Next.js 15 (App Router) + Tailwind v4 + Supabase Auth. ChatGPT형 레이아웃(사이드바 1행 기능 · 2행 최근 검색 · 우측 원문 뷰어).

```bash
cp .env.example .env.local   # Supabase URL·anon 키, AI 백엔드 주소
npm install
npm run dev                  # http://localhost:3000
```

설치·배포 전체 순서는 저장소 루트의 `docs/setup.md`.

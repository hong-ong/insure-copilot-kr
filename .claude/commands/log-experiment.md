"$ARGUMENTS" 를 `docs/learning-log.md`에 템플릿 형식으로 추가한다.

- 날짜는 오늘, 주차는 README 진행 현황에서 🟡인 주차.
- 가설·방법·결과는 이 대화와 `eval/results/`·스크립트 출력에서 확인한 사실만 쓴다. 숫자를 지어내지 않는다.
- **배운 점은 비워 두고** 사용자에게 한두 문장으로 직접 채워 달라고 요청한다.
- 결과가 나빠도 그대로 기록한다.

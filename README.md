# insure-copilot-kr

> 보험 설계사·상담원이 약관·규정을 **출처와 함께** 확인하고, 교육·영업 지표를 **권한 범위 안에서** 조회하는 사내 AI 어시스턴트 (개인 포트폴리오 프로젝트)

🚧 **진행 중 — 1주차 (문제 정의와 개발 환경)**

## 무엇을 하나

| 질문 유형 | 예시 | 처리 |
| --- | --- | --- |
| 약관·규정 | "실손보험에서 도수치료는 어떻게 보장되나요?" | 표준약관·보험업법·분쟁조정사례 검색(RAG) → 근거 조문·약관 버전 표시 |
| 지표 | "이번 분기 강남지점 보수교육 이수율은?" | 미리 정의한 지표(시맨틱 레이어)로 계산, 역할별 조회 범위 제한 |
| 판단 요구 | "이 고객 보험금 받을 수 있나요?" | 근거 조문만 안내하고 판단은 거절, 담당 부서 안내 |

```
질문 → 라우터 ─┬─ 약관·규정 RAG ─┐
               ├─ GenBI ─────────┼─→ 답변 검증 → 사용자
               └─ 거절 ──────────┘
공통 층: LiteLLM 게이트웨이 · Langfuse 트레이스 · 골든셋 회귀 평가
```

## 실행 방법

```bash

# 2. API 키 설정
cp .env.example .env   # 그다음 .env에 키 입력

# 3. 테스트
uv run pytest
```

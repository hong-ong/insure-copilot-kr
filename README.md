# insure-copilot-kr — 가온생명 AX 어시스턴트

> 보험 설계사·창구 직원·본사 법무팀이 약관·규정을 **출처(약관명·조항·판)와 함께** 확인하고, 실적·교육 지표를 **권한 범위 안에서** 조회하는 사내 AI 어시스턴트 (개인 포트폴리오 프로젝트)

🚧 **진행 중 — 10 → 1 방식: 서비스 1차 완성 → 기능별 갭 체크·실험 단계**
가온생명은 가상 보험사이며, 모든 약관·사내 문서·실적 데이터는 가상입니다.

## 무엇을 하나

| 질문 유형 | 예시 | 처리 |
| --- | --- | --- |
| 약관·규정 | "실비로 도수치료 몇 번까지 돼?" | 검색(RAG) → 근거 조항·약관 판 표시, 출처 클릭 시 원문 해당 조항 하이라이트. 개정 전 가입자 안내 자동 추가 |
| 지표 | "이번 분기 지점별 보수교육 이수율" | LLM은 지표·차원·기간만 고르고 계산은 정의된 SQL(시맨틱 레이어). 설계사는 본인 실적만 |
| 판단 요구 | "이 고객 보험금 받을 수 있어?" | 판단은 거절, 관련 조문만 안내 → `법무팀에 문의` |
| 회의록 | 회의 메모 붙여 넣기 | 표준 양식(결정 사항·액션아이템) AI 초안 → 사람이 확정 → 검색 근거로 편입 |
| 파일 업로드 | 약관 개정안 PDF·HWP | 자체 파서 → 한글 인식률 90% 이상 자동 승인 → 이전 판 보존 + 신구대비표 자동 생성 |

```
질문 → 마스킹 → 라우터 ─┬─ 약관·규정 RAG ─┐
                        ├─ GenBI ──────────┼─→ 답변 검증(근거 없으면 거절) → 사용자
                        └─ 거절 ───────────┘
공통 층: LiteLLM 게이트웨이(fallback·비용) · Supabase RLS 권한 · 토큰·비용·지연 로그 · 피드백 → 골든셋 후보
```

## 화면

- ChatGPT형 레이아웃 — 사이드바 1행 **검색 · 파일 업로드 · 회의록**, 2행 **최근 검색**, 우측 **원문 뷰어**
- 로그인: 이메일 · Google · Kakao(Supabase Auth) + 가입 없이 **데모 체험 3종**(설계사 / 본사 법무팀 / AX 관리자, 하루 10회)
- 법무팀: 판단 문의함 · 개정 영향 분석 · 신구대비표 검토 · 👎 피드백 검토 / AX 관리자: 평가 대시보드 · 비용·토큰·로그
- AI 사용 고지: 첫 진입 동의 모달 · 입력창 하단 상시 문구 · 답변 'AI 생성' 라벨 · 회의록 'AI 생성 초안'

## 실행 방법

자세한 순서(Supabase 설정, OAuth, 배포)는 [`docs/setup.md`](docs/setup.md).

```bash
uv sync && uv run pytest                                   # 백엔드 테스트 (네트워크 없이 돈다)
uv run python scripts/seed_demo.py                          # 가상 문서·개정안·회의록 적재
uv run uvicorn insure_copilot.api.main:app --reload         # AI 백엔드 :8000
cd web && npm install && npm run dev                        # 화면 :3000
```
